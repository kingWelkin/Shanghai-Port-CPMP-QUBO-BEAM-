## Gate Result

Do not promote v4.2 as mainline yet.

The candidate improves path length materially on common solved cases, especially CV large cases, but it loses one CV case that v4.0 solved. The strict promotion rule is solved count first, then moves, then runtime, so this full gate rejects promotion.

## Decision

Keep v4.0 as the promoted mainline. Keep v4.2 as an experimental quality candidate.

Next work should not broaden v4.2 blindly. The narrow fix is:

1. Trace `CV/10-6/data10-6-13` to find why short-incumbent/postcompress blocks the v4.0 feasible route.
2. Add a conservative guard that preserves v4.0's original solved path when v4.2 cannot finish inside the same search envelope.
3. Re-run the full open120 + BF + CV t120 paired gate before any promotion.
