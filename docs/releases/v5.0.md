# QUBO–Beam v5.0 研究发布

日期：2026-10-13

本次发布对应客户说明中的 **Q+Pair**：v4.3 前端生成完整合法路径，多箱整条路线 QUBO 与独立 Pair 按完整轮次交替执行，FRG 持续精炼，共享原始截止时间。

## 发布内容

- 与研究代码一致的联合路线建模、因子表示、结构化有界搜索、暖启动、双轨调度、FRG 和物理回放代码及必要传递依赖。

- BF/CV/Open120 公开基准、hardset169 精确清单和来源说明。
- 客户 Markdown、完整 PNG/SVG 流程图及 Mermaid 源码。
- 两套困难集摘要、逐次结果表、约束/能量/路线见证，以及扩预算和长尾诊断摘要。
- 相关模型、轨迹、预算与回放测试；实验性的延后 Pair 和三轨保护源码。

发布入口为便于源码使用新增的适配层，没有修改 Q+Pair 的模型、搜索参数、种子定义或轮次调度。可选远程硬件接口移除了旧内网地址，改为显式环境配置；当前主方案使用本地经典后端。

本发布以独立快照提交保存，只含所列内容。研究来源的基础提交为 `53f0d192fa867cc98e218dfeccb6b6fda3b72ab6`，叠加截至本次发布的 v5.0 研究实现；原研究工作目录和历史均保留。
