## 直接结论

- v4.3 是表中唯一在四套算例上全部求解成功的算法：合计 `1,711/1,711`。
- Open120、BF、CV 的主线已解翻箱总步数分别为 `3,759`、`45,906`、`55,865`。
- 低覆盖算法的步数只累计已解算例，不能脱离解出率直接判为路径更短。
- Real30 主线的固定口径是 `525` 步；`516` 步属于论文 BS-FRG。

## 口径

每个单元格第一行是 `已解数/总数`，第二行是**已解算例的翻箱步数总和**。
未解算例不计入步数，因此先比较解出率，再在覆盖接近时比较步数。`不适用`
表示该历史对照没有扩展到相应数据集，不表示求解数为零。

不同论文基线来自已有历史运行，时间预算并不完全相同。本表用于固定项目当前采用的
历史比较口径，不宣称统一预算下的全新 paired rerun。
