# BS-FRG QUBO Selector Design

## Goal

Add an opt-in BS-FRG QUBO selector on top of `scheduler_state_v5_wang_rescue_polish` to test whether QUBO-based quality-diversity beam selection can improve the current best compact CPMP route without changing the default baseline.

## Baseline

The base profile is `scheduler_state_v5_wang_rescue_polish`. It keeps the existing beam widths, Wang pair-QUBO supplement, rescue QUBO, and post-polish QUBO behavior. The new selector is an ablation switch and must not replace the default v5 path.

## Selector

The selector runs inside `_select_enhanced_qubo_frontier` after deterministic core and existing Wang/FRG deterministic supplements, before generic QUBO fill. It sees only legal child layouts already generated by compact beam search.

For each candidate, it computes a linear quality energy from:

- normalized FRG transition score from parent layout to child layout;
- normalized rank position inside the layer candidate list;
- child `N` value and depth as tie breakers.

For candidate pairs, it adds similarity penalties based on code-stable features:

- same parent code;
- same child `N` band;
- same FRG transition signature.

It uses an exactly-k penalty to select a fixed supplement width. This keeps crane-move feasibility outside the QUBO, so a bad QUBO sample can only choose a weaker survivor set, not an illegal move.

## Gates

The selector is active only when:

- `bs_frg_qubo_enabled` is true;
- `use_qubo` is true;
- `candidate_count >= bs_frg_qubo_min_candidates`;
- `best_n <= bs_frg_qubo_focus_n`, unless focus is negative;
- the current layer has enough remaining beam capacity.

## Telemetry

Rows must expose:

- `bs_frg_qubo_enabled`;
- `bs_frg_qubo_supplement_width`;
- `bs_frg_qubo_calls`;
- `bs_frg_qubo_vars`;
- `bs_frg_qubo_time_sec`;
- `bs_frg_qubo_selected_total`.

## Validation

First run focused unit tests for the selector and CLI/profile plumbing. Then run a small open slice against the current v5 baseline. Only if it preserves coverage should it be tested on open120 at 20 seconds.
