> [!IMPORTANT]

Date: 2026-07-01

This repository studies container pre-marshalling / CPMP search for Shanghai Port style layouts. The current engineering line is a compact byte-state beam search with QUBO-assisted frontier selection. QUBO is not used to generate crane moves; it only selects among already legal candidate states and replayable macro-chain candidates generated by the classical search engine.

## What The Mainline Does

At each beam layer:

1. Generate legal one-step CPMP child states with the compact classical engine.
2. Build short BS-FRG-style recovery chains from selected frontier parents.
3. Lift replayable chain prefixes into macro candidates only when they carry completion-witness evidence.
4. Score normal and macro candidates by progress, path cost, receiver debt, source scarcity, and witness quality.
5. Keep a deterministic core to protect the strongest candidates.
6. Use a small union QUBO selector to add quality-diverse exploration candidates.
7. Store selected macro-chain compact paths in the lineage metadata.
8. When an `N=0` terminal is found, backtrack the compact lineage.
9. Expand macro edges, repair compact successor gaps, lift to crane moves, and validator-replay.
10. Apply post-polish only after a valid `N=0` path exists.

Compared with macro credit v2:

- v2 rewarded local macro features;
- macro-chain witness selects a future-bearing object;
- receiver debt is still a penalty pressure, not a free positive credit;
- source scarcity helps judge whether the chain is structurally plausible;
- compact-path repair protects reconstruction from skipped macro transitions.

## Boundaries

Avoid:

- neural or data-trained policies;
- solver portfolio fallback that simply runs multiple algorithms and takes the best;
- case-name-specific gates;
- full BS-FRG as a failure fallback inside the mainline;
- changes that improve one residual case while adding open120, BF, or CV regressions;
- hardcoded mechanisms that cannot be ablated.

Prefer:

- ablation-friendly feature switches;
- one candidate pool and one selector path;
- paired runs against the current mainline and the previous v2 baseline;
- telemetry that tells whether useful children are absent, generated-but-not-selected, selected-then-dead, or lost during compact lifting.

## Current Remaining Failure And Risk Classes

- `BF27/cpmp_20_8_96_39_58_16`: remaining primary miss; feasible path found but over the primary time boundary in the original full run.
- CV common-solved path length: pure BS-FRG is often shorter on CV rows, so the next quality work should reduce path debt without giving up macro-chain coverage.
- Reproducibility hygiene: a same-command full BF/CV rerun can refresh the patched aggregate, but the known compact-lift failures have already been replaced.
