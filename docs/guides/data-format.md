# 数据格式

## 文件组织

默认多贝位合并模式要求同一箱区同时存在两个输入文件：

```text
data/input/{ZONE}_01_input.txt
data/input/{ZONE}_26_input.txt
```

示例：

```text
data/input/A1_01_input.txt
data/input/A1_26_input.txt
```

程序会把它们合并为一个案例：

```text
A1_01_26_paired
```

## 行格式

每行两个字段，用空白分隔：

```text
位置编码 关序号
```

示例：

```text
A10111 6044
A12646 5345
```

空行和以 `#` 开头的行会被跳过。

## 位置编码

位置编码固定 6 位：

```text
ii jj k X
|  |  | |
|  |  | +-- 层号，1-6
|  |  +---- 排号，1-9 或 A，A 表示第 10 排
|  +------- 贝位号，例如 01 或 26
+---------- 箱区号，例如 A1、B2、C5
```

例如：

```text
A101A1
```

含义：

- 箱区：`A1`
- 贝位：`01`
- 排号：`A`，即第 10 排
- 层号：`1`

## 关序号

关序号是整数。当前排序判断直接使用关序号大小：

- 关序号小的箱更早装船。
- 良序要求：下层关序号大于上层关序号。

也就是说，一堆从底到顶应满足：

```text
seq(layer 1) > seq(layer 2) > seq(layer 3) > ...
```

## 合并规则

多贝位合并时：

- 每个贝位固定 10 堆。
- `01` 贝位映射到全局堆 `1..10`。
- `26` 贝位映射到全局堆 `11..20`。
- 全场共用一套按关序号排序得到的箱秩。
- 允许跨贝位搬顶箱，例如 `26-5 -> 01-4`。
