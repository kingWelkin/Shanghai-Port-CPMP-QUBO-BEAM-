--------------------------------------------------------------------------------
【数据格式详解】
--------------------------------------------------------------------------------

每一行包含两个数据，以空格分隔：
  [位置编码] [关序号]

位置编码格式 (固定 6 位)：
  ii jj k X
  |  |  | |
  |  |  | +-- 层号 (Layer): 1-6
  |  |  +---- 排号 (Row): 1-9 或 A (A=10)
  |  +------- 贝位号 (Bay): 01 或 26
  +---------- 箱区号 (Zone): A1, B2, C5 等
  

关序号格式：  
	固定为整数，关序号小的先装船
  
  
+-----------------------------------------------------------------------+
|  实际堆存视图 (侧面)                                                 |
|  A101A1 A101A1 A10191 A10121 A10122                                  |
|                                                                      |
|  层 (X)                                                              |
|  ^                                                                   |
|  |   +---+---+---+   ...   +---+---+---+   (第6层，最高限制)         |
|  6   |   |   |   |         |   |   |   |                             |
|  |   +---+---+---+   ...   +---+---+---+                             |
|  5   |   |   |   |         |   |   |   |                             |
|  |   +---+---+---+   ...   +---+---+---+                             |
|  4   |   |   |   |         |   |   |   |                             |
|  |   +---+---+---+   ...   +---+---+---+                             |
|  3   |   |   |   |         |   |   |   |                             |
|  |   +---+---+---+   ...   +---+---+---+                             |
|  2   |   | √ |   |         |   |   | √ |                            |
|  |   +---+---+---+   ...   +---+---+---+                             |
|  1   |   | √ |   |         |   | √ | √ |  <-- 地面 (第1层，必须存在) |
|  +---+---+---+---+---...---+---+---+---+---+---+---+---+---+---+---+
|      1    2    3     ...   8    9    A(10)                           |
|  <---------------------- 排 (k) 方向 ------------------------------->|
|                                                                      |
|  箱区 (ii): A1      贝位 (jj): 01                                    |
+----------------------------------------------------------------------+
        |           |
        |           +---> 贝位号 (固定2位: 01 或 26)
        |
        +-------------> 箱区号 (固定2位: A1, B2, C5 等)
