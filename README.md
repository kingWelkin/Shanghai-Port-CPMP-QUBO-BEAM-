# Shanghai Port CPMP QUBO Beam

This repository contains engineering experiments for container pre-marshalling / CPMP on Shanghai Port style layouts. The active solver family is a compact byte-state beam search with QUBO-assisted frontier selection and post-polish path compression.

## Current Mainline

The current open and paper benchmark mainline candidate is:

```text
qubo_scheduler_state_v5_qubo_diversity_union_polish
```

The paired baseline remains:

```text
qubo_scheduler_state_v5_wang_rescue_polish
```

`wang_rescue_polish` is still the clean comparison point, but the diversity-union profile is the stronger current candidate on the combined open120 and paper sample evidence.

## Mechanism Boundary

QUBO is used as a beam-selection helper, not as a move generator.

- Legal child states are still generated by the classical compact beam engine.
- The union QUBO selector picks a small number of diverse exploration states from already legal candidates.
- Pair penalties discourage selecting candidates with the same parent, same source stack, same transition signature, same reduce signature, or same n-band.
- Validator replay remains the final feasibility check.
- BS-FRG-derived frontier children are experimental candidate support, not a BS-FRG fallback solver.

## Main Commands

Run the current open120 mainline:

```powershell
python scripts\open_cpmp_benchmarks.py --source external\DLTS --no-auto-clone --families 5x5_cv1_test 5x5_cv2_test 5x5_cv3_test 7x5_cv1_test 7x5_cv2_test 7x5_cv3_test --limit-per-family 20 --variant qubo_scheduler_state_v5_qubo_diversity_union_polish --time-limit 10 --alpha 10 --jobs 8 --output docs\experiments\mainline_union_open120_t10.csv
```

Run the paper BF/CV sample gate:

```powershell
python scripts\benchmark_compact_paper_set.py --source external\paper_cpmp --datasets BF CV --sample-per-family 10 --variant qubo_scheduler_state_v5_qubo_diversity_union_polish --time-limit 20 --alpha 10 --jobs 8 --output docs\experiments\mainline_union_paper_sample10_t20.csv
```

Run focused regression tests for the current union/frontier work:

```powershell
$env:PYTHONPATH='.'; $env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'; python -m pytest tests\test_qubo.py -k "union_rollout or frg_frontier_child or qubo_diversity_union or bs_frg_qubo" -q --basetemp .tmp_pytest_commit_union
```

Compile-check the main benchmark scripts:

```powershell
$env:PYTHONPATH='.'; python -m py_compile scripts\benchmark_compact_beam_qubo_n0.py scripts\open_cpmp_benchmarks.py scripts\benchmark_compact_paper_set.py scripts\benchmark_classical_cpmp_baselines.py scripts\benchmark_target_astar_memory_n0.py scripts\benchmark_bs_frg_cpmp.py scripts\run_bs_frg_bf14_failed_unlimited.py
```

## Experimental Branches

These profiles are implemented for ablation and diagnosis, but are not the default mainline:

| profile | purpose | status |
|---|---|---|
| `qubo_scheduler_state_v5_qubo_diversity_union_rollout_polish` | add a bounded FRG-style rollout probe as a selection signal | ablation |
| `qubo_scheduler_state_v5_qubo_diversity_union_rollout_graft_polish` | graft a validated rollout-complete tail when available | ablation |
| `qubo_scheduler_state_v5_qubo_diversity_union_frg_frontier_polish` | append BS-FRG-generated child states after normal frontier selection | light frontier experiment |
| `qubo_scheduler_state_v5_qubo_diversity_union_frg_single_frontier_polish` | merge FRG-generated children into the same candidate pool before selection | experimental |
| `qubo_scheduler_state_v5_qubo_diversity_union_frg_frontier_adaptive_polish` | expand FRG frontier support on high-n plateau or small-stack pressure | ablation |

Promotion requires paired improvement on both open120 and the paper-set gate.
