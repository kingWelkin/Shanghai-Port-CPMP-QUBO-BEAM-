# Shanghai Port CPMP QUBO Beam

This repository contains engineering experiments for container pre-marshalling /
CPMP on Shanghai Port style layouts. The current v4.0 mainline is a compact
byte-state beam search with QUBO-assisted frontier selection, BS-FRG-inspired
macro-chain candidate supply, and validator-checked path reconstruction.

## v4.0 Mainline

The promoted v4.0 profile is:

```text
qubo_scheduler_state_v5_qubo_diversity_union_unified_macro_supply_chainaware_polish
```

It supersedes the previous macro-chain witness line:

```text
qubo_scheduler_state_v5_qubo_diversity_union_macro_chain_witness_polish
```

The v4.0 profile keeps the same single-search architecture: legal states are
generated by the compact CPMP engine, QUBO only selects beam survivors, and
BS-FRG contributes bounded recovery-chain candidates rather than acting as an
external fallback solver.

## Mechanism Boundary

QUBO is used as a beam-selection helper, not as a move generator.

- Legal one-step children are generated by the compact CPMP transition engine.
- Wang-style pair/fixed-prefix features are local state quality signals.
- BS-FRG-style completion probes create bounded macro-chain candidates.
- Unified macro supply adds extra recovery-chain candidates from deeper parent
  offsets when candidate pressure is high.
- Chain-aware QUBO scoring penalizes over-reusing the same macro ancestry.
- Selected macro candidates are expanded back into compact state paths.
- Compact path gaps are repaired before lifting to physical crane moves.
- Validator replay remains the final feasibility boundary.

The practical reading: v4.0 lets QUBO choose among ordinary children and
future-proven recovery-chain objects in one beam, while keeping one solver path
and one validator boundary.

## Main Commands

Run the current open120 no-cap mainline:

```powershell
python scripts\open_cpmp_benchmarks.py --source external\DLTS --no-auto-clone --families 5x5_cv1_test 5x5_cv2_test 5x5_cv3_test 7x5_cv1_test 7x5_cv2_test 7x5_cv3_test --limit-per-family 20 --variant qubo_scheduler_state_v5_qubo_diversity_union_unified_macro_supply_chainaware_polish --time-limit 120 --alpha 10 --jobs 8 --no-business-cap --output docs\experiments\v4_open120_t120.csv
```

Run the full paper BF/CV no-cap gate:

```powershell
python scripts\benchmark_compact_paper_set.py --source external\paper_cpmp --datasets BF CV --sample-per-family 9999 --variant qubo_scheduler_state_v5_qubo_diversity_union_unified_macro_supply_chainaware_polish --time-limit 120 --alpha 10 --jobs 8 --no-business-cap --output docs\experiments\v4_paper_bf_cv_full1561_t120.csv
```

Run focused regression tests:

```powershell
$env:PYTHONPATH='.'; $env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'; python -m pytest tests\test_qubo.py tests\test_bs_frg_paper_benchmarks.py tests\test_current_mainline_union.py -q
```

Compile-check the benchmark entrypoints:

```powershell
$env:PYTHONPATH='.'; python -m py_compile scripts\benchmark_compact_beam_qubo_n0.py scripts\open_cpmp_benchmarks.py scripts\benchmark_compact_paper_set.py
```
