# Shanghai Port CPMP QUBO Beam

This repository contains engineering experiments for container pre-marshalling / CPMP on Shanghai Port style layouts. The active research line is a compact byte-state beam search with QUBO-assisted frontier selection and post-polish path compression.

## Current Mainline

The current promoted open120 plus paper BF/CV benchmark mainline is:

```text
qubo_scheduler_state_v5_qubo_diversity_union_macro_credit_v2_polish
```

The clean historical paired baseline remains:

```text
qubo_scheduler_state_v5_wang_rescue_polish
```

The open120-only full-coverage path-quality reference is:

```text
qubo_scheduler_state_v5_qubo_diversity_union_frg_macro_edge_qubo_polish
```

`macro_credit_v2` is promoted because open120 and BF/CV paper-set performance are now treated as equally important. It keeps open120 at full coverage while giving the best current paper BF/CV sample1 result.

## Mechanism Boundary

QUBO is used as a beam-selection helper, not as a move generator.

- Legal child states are generated by the classical compact beam engine.
- The union QUBO selector picks a small number of exploration states from already legal candidates.
- Macro credit v2 rewards recovery candidates only when they carry completion-witness or macro-path evidence.
- Receiver debt is a penalty pressure in v2, not a free positive credit.
- Validator replay remains the final feasibility check.
- BS-FRG-derived frontier children and macro chains are candidate-selection support, not fallback solvers.

## Experimental Branches

These profiles are implemented for ablation and diagnosis, but are not the default mainline:

| profile | purpose | status |
|---|---|---|
| `qubo_scheduler_state_v5_qubo_diversity_union_macro_credit_polish` | v1 macro future credit | superseded by v2 |
| `qubo_scheduler_state_v5_qubo_diversity_union_rollout_polish` | bounded FRG-style rollout probe as a selection signal | ablation |
| `qubo_scheduler_state_v5_qubo_diversity_union_rollout_graft_polish` | graft a validated rollout-complete tail when available | ablation |
| `qubo_scheduler_state_v5_qubo_diversity_union_micro_tiebreak_polish` | use micro rollout only for near-tied candidates | ablation; paper-set penalty regressed |
| `qubo_scheduler_state_v5_qubo_diversity_union_frg_frontier_polish` | append BS-FRG-generated child states after normal frontier selection | light frontier experiment |
| `qubo_scheduler_state_v5_qubo_diversity_union_frg_single_frontier_polish` | merge FRG-generated children into the same candidate pool before selection | experimental |
| `qubo_scheduler_state_v5_qubo_diversity_union_debt_basin_polish` | receiver-debt, escape-potential, basin-diversity, and reduction-chain selector signals | diagnostic; failed paper sample10 promotion gate |
| `qubo_scheduler_state_v5_qubo_diversity_union_frg_frontier_adaptive_polish` | expand FRG frontier support on high-n plateau or small-stack pressure | ablation |

Promotion requires paired improvement on both open120 and the paper-set gate.
